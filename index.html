NetSentinel — Network Security Scanner in Go

Open-source network security scanner built from scratch in Go (v3.0.0). Performs parallel host discovery and concurrent TCP port scanning using goroutine worker pools, captures service banners, resolves hostnames via reverse DNS, and enriches every finding with known CVEs queried live from the NVD API — with rate limiting and disk caching. Produces terminal, JSON and HTML reports, and ships cross-compiled binaries for Windows and Linux (amd64/arm64) through versioned GitHub Releases.

AzRBAC Auditor — Azure IAM Posture Scanner in Go

Open-source CLI tool for auditing identity and access management (IAM) in Azure subscriptions. Authenticates via OAuth2 client credentials, enumerates all RBAC role assignments, resolves GUIDs to human-readable names using Microsoft Graph API, and detects security misconfigurations: privileged roles assigned directly to users, guest accounts with elevated permissions, and service principal secrets expiring soon. Generates executive reports in HTML (with color-coded severity badges) and JSON. Built to run on any Azure tenant without requiring premium licenses.
